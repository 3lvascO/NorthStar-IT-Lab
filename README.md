# NorthStar-IT-Lab

## Objective

Build and manage a virtualized Windows environment to develop practical skills in Windows system administration and IT support. This project focuses on configuring Windows Server and client systems, implementing Active Directory and Group Policy, managing user accounts and permissions, troubleshooting connectivity and authentication issues, and documenting technical problems and their resolutions. The goal is to simulate real-world IT support scenarios and demonstrate hands-on skills in system administration, troubleshooting, and enterprise IT operations.

## Skills Demonstrated

- **Windows System Administration:** Windows Server and Windows client configuration and management
- **Active Directory (AD DS):** Domain setup, user and group management, and centralized authentication
- **Group Policy (GPO):** Centralized configuration and enforcement of Windows security settings
- **User and Access Management:** Account administration, permissions, and access control
- **IT Troubleshooting:** Systematic diagnosis and resolution of operating system, authentication, and configuration issues
- **Networking Fundamentals:** IP addressing, DNS, network connectivity, and domain communication
- **Virtualization:** Virtual machine deployment, configuration, and management
- **Windows Security:** Security policies, least privilege, and system hardening
- **Technical Documentation:** Recording system configurations, troubleshooting procedures, test results, and resolutions
- **PowerShell:** Basic Windows administration and automation, where implemented

## Tools & Technologies

### Virtualization and Lab Environment
- **Virtualization Platform:** Oracle VirtualBox
- **Windows Server:** Domain services and centralized administration
- **Windows 10/11:** Client configuration and support

### Windows Administration
- **Active Directory Users and Computers (ADUC):** User, group, and account administration
- **Group Policy Management Console (GPMC):** Centralized policy configuration
- **Server Manager:** Windows Server roles and feature management
- **PowerShell:** Command-line administration, diagnostics, and automation

### Networking and Troubleshooting
- **Command Prompt:** Basic system diagnostics and network troubleshooting
- **ipconfig:** IP configuration and DNS troubleshooting
- **ping:** Basic connectivity testing
- **nslookup:** DNS resolution testing
- **gpresult:** Group Policy verification
- **Event Viewer:** System and application log analysis

### Documentation and Version Control
- **Git:** Version control and tracking project changes
